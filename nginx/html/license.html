01协议范围与接受方式

本协议适用于 mobufan 脚本工具箱（下称「本工具箱」），包括主脚本 mobufan.sh、一键安装脚本，以及仓库内附带的 Nginx、Fail2ban、BBR、Docker Compose、系统工具与媒体文件重命名等配置与脚本。

首次运行主脚本时，终端会提示阅读本协议并要求输入 y 或 N：输入 y 即表示你已完整阅读、理解并接受全部条款；输入 N 或直接回车，脚本将退出，你无法继续使用本工具箱。

本工具箱基于 kejilion.sh 二次开发，仅用于个人学习、研究与自有服务器的管理维护。原项目及其依赖组件的授权归各自权利人所有。

本工具箱并非面向生产环境发行的通用软件，作者未承诺持续维护、版本兼容或技术支持。

03系统级操作与使用风险

本工具箱中的功能会执行系统级变更，包括但不限于：

  • 安装 / 卸载系统软件包、更换 TCP 拥塞控制算法与内核；
  • 修改 SSH / sshd 配置、部署 SSL 证书与 Nginx 站点、配置 Fail2ban 封禁规则；
  • 创建、停止、删除 Docker 容器与镜像，备份 / 恢复 Compose 配置；
  • 磁盘分区、挂载、文件压缩解压与定向删除，以及剧集文件批量重命名。

请特别注意：大量配置与逻辑仅适配作者本人的本地环境（目录结构、服务器 IP、个人偏好等），未做通用性兼容处理，不保证在其他设备或系统中正常运行。执行任何操作前请自行备份数据，并先在测试环境验证。

05网络安全与数据

脚本会从 Gitee、GitHub 及作者自建站点拉取主脚本与更新日志。自 v1.8.2 起，远程脚本统一采用 HTTPS 下载，并在执行前进行 Bash 语法检查与可选的 sha256 校验；已移除明文 HTTP 下载与跳过证书校验的行为。你仍应自行核验下载源的可信度。

部分功能会访问第三方服务（如 ipinfo.io）以检测网络地区与公网 IP。脚本不会主动上传你的服务器数据，但涉及 SMB、MySQL 等凭据的功能请自行妥善保管，避免写入明文或共享环境。

06非交互环境

在 cron、SSH 远程单条命令、CI 等非交互场景下，脚本不会弹出协议确认，也不会代替你写入同意状态，仅提示跳过。建议至少以交互方式运行一次，主动完成协议确认。

07同意状态的记录与撤回

同意状态仅保存在你自己的设备上，以当前用户主目录下的 ~/.mobufan_license 文件内容为 agreed 为准。执行脚本自带的卸载功能时，该文件会被一并删除，下次安装运行将重新提示确认。

你可以随时删除该文件以撤回同意并重新阅读本协议。
